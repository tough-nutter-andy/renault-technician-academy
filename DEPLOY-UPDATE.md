# Publish the Forced Ignition Hints & Tips update

1. Extract the ZIP and open the `renault-technician-academy` folder.
2. In GitHub, update the project files at the repository root. Most importantly upload/replace `src/main.jsx`, `src/style.css`, and add `public/forced-ignition-procedure.mp4` and `public/forced-ignition-poster.jpg`.
3. If your GitHub interface cannot replace an existing file by upload, use the web editor for text files or drag-and-drop a complete updated folder through GitHub Desktop. Do not create a second nested project folder.
4. Commit to `main`; Vercel should automatically start a new deployment. Check the Vercel build result.
5. Open **Learn → Hints & Tips** and play **Forced Ignition Procedure**.

This video is ~14 MB. Check content permission and access protection before sharing a live URL. The project is still a prototype using local browser progress, not technician accounts.
